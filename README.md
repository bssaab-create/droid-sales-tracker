
# Droid Sales Tracker

A simple sales pipeline tracker used to test Factory.ai Droid.

## Features

- Add a sales lead
- Track company and contact
- Enter potential deal value
- Assign a sales stage
- View total pipeline
- View closed-won revenue

## Sales Stages

- Prospect
- Discovery
- Demo
- Closed Won
- Closed Lost

## Goal

Build a simple web application that demonstrates these features.
Keep the interface simple and easy to use.
